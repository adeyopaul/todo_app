# Todo App

A Flutter task-management application built as a personal learning project to practise core Flutter development, responsive UI, theming, navigation, and reusable application structure.

## Project Status

**Learning/demo project — not a production or client application.**

## Overview

The app is titled **UpTodo** and focuses on a clean task-management experience with:

- Splash screen
- Login screen
- Main application/index screen
- Light and dark themes
- Responsive layouts
- Native splash screen
- Structured Flutter presentation and theme layers

## Tech Stack

- **Flutter**
- **Dart**
- **flutter_screenutil** — responsive sizing and layout adaptation
- **flutter_native_splash** — native splash screen
- **smooth_page_indicator**
- **Cupertino Icons**

## What I Practised

- Building Flutter interfaces from a design reference
- Responsive UI with `flutter_screenutil`
- Light and dark theme configuration
- Flutter navigation and screen organisation
- Reusable widgets and project structure
- Native splash-screen configuration
- Dart asynchronous programming

## Project Structure

```text
lib/

```

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or another Flutter-compatible IDE

### Installation

```bash
git clone https://github.com/adeyopaul/todo_app.git
cd todo_app
flutter pub get
flutter run
```
